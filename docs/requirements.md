# 요구사항 정의 문서

- F14~F20 까지의 입력 지원
- 동시에 5개 이상 키보드 눌림처리 지원
- 디바운싱
  - 한 번 누르고 떼면 정확히 눌림 1회, 뗌 1회로 처리
  - 키마다 독립적으로 디바운싱
- GP0 부터 GP12 까지 2간격으로 핀 사용
- 각 키는 F14~F20에 매핑
- PC에 연결하면 USB HID 키보드로 인식
- 별도 드라이버 설치 없이 Windows 기본 드라이버로 동작
- 케이블을 뽑았다 다시 꽂으면 다시 정상 인식
- 한 키를 누른 채 다른 키를 누르고 떼도, 먼저 누른 키는 계속 눌린 상태로 유지
- 키의 상태가 바뀔 때마다 리포트를 전송
- 리포트에는 그 시점에 눌려 있는 키 전체가 담김
- 전원이 들어오면 별도 조작 없이 동작을 시작
- 전원 인가 시 이미 눌려 있던 키는 한 번 뗄 때까지 무시
